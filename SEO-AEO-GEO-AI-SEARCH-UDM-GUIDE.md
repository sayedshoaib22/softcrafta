# 1. SEO

SEO = Search Engine Optimization.

Purpose: improve SoftCrafta's discoverability, relevance, crawlability, indexability, technical quality, and organic search performance.

SEO is not simply inserting keywords into pages. Good SEO requires a system of technical quality, clear content, useful structure, semantic relevance, and user intent alignment.

## SEO areas that matter for SoftCrafta

- Technical SEO
- On-page SEO
- Content SEO
- Keyword research
- Search intent
- Internal linking
- Image SEO
- Schema markup
- Core Web Vitals
- Mobile SEO
- Local SEO
- Off-page authority
- Content freshness

## SEO principles for SoftCrafta

1. Build pages around real search intent.
2. Make the page useful before optimizing for keywords.
3. Ensure important content is crawlable and indexable.
4. Keep page structure clear and semantic.
5. Use strong internal linking across service pages and guides.
6. Create original, specific content tied to real services and work.
7. Keep metadata accurate and descriptive.
8. Use schema that reflects what is actually visible on the page.

# 2. AEO

AEO = Answer Engine Optimization.

Purpose: make information easier for answer-oriented systems to understand and potentially surface as direct answers.

AEO supports answer-driven experiences such as featured snippets, question-answer summaries, and direct-answer content blocks.

## AEO principles

- Question-based content
- Direct answers
- Definitions
- FAQ content
- Lists
- Tables
- Structured explanations
- Clear headings
- Concise answer paragraphs
- Supporting evidence
- Internal linking

```text
↓
```

# 3. GEO — Generative Engine Optimization

## GEO — Generative Engine Optimization

GEO is the practice of improving the clarity, authority, entity understanding, source quality, and usefulness of content for generative AI search and answer experiences.

GEO overlaps with AEO and AI Search Optimization, but it focuses particularly on generative systems that synthesize information from multiple sources.

## GEO priorities for SoftCrafta

- Entity clarity
- Brand consistency
- Original content
- First-hand experience
- Case studies
- Expert/company authorship
- Factual accuracy
- Clear explanations
- Citations
- Source quality
- Topical authority
- Semantic relationships
- Internal linking
- External references
- Content freshness
- Structured data
- Crawlability

## GEO warning

There is no guaranteed GEO formula that forces an AI system to mention SoftCrafta. GEO should improve clarity, usefulness, and trust, but it cannot guarantee mentions, citations, or recommendations.

## GEO quality checklist

- Does the page clearly identify SoftCrafta and its services?
- Is the content original and fact-based?
- Are claims supported by real evidence?
- Does the page explain from a real business perspective?
- Are case studies and portfolio elements helpful?
- Is the page linked to related service pages and trust-building content?

# 9. Structured data

Structured data helps machines understand content more clearly. It should reflect real content and not invent facts.

## Structured data types relevant to SoftCrafta

- LocalBusiness only when appropriate and verifiable
- WebSite
- WebPage
- Service
- BreadcrumbList
- Article
- FAQPage when appropriate
- Review structured data when appropriate

## Rules for structured data

- No fake information.
- No fake ratings.
- No fake reviews.
- No fake review counts.
- No fake awards.
- No fake prices.
- Structured data must accurately represent visible content.

## Example: Organization JSON-LD

```json
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "SoftCrafta",
  "url": "https://softcrafta.in/",
  "description": "SoftCrafta is a web development and software services agency.",
  "sameAs": [
    "https://softcrafta.in/"
  ],
  "knowsAbout": [
    "Website Development",
    "SEO",
    "Google Business Profile Optimization",
    "Custom Software Development"
  ]
}
```

## Example: WebSite JSON-LD

```json
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "name": "SoftCrafta",
  "url": "https://softcrafta.in/",
  "potentialAction": {
    "@type": "SearchAction",
    "target": "https://softcrafta.in/?q={search_term_string}",
    "query-input": "required name=search_term_string"
  }
}
```

## Example: Service JSON-LD

```json
{
  "@context": "https://schema.org",
  "@type": "Service",
  "serviceType": "SEO",
  "provider": {
    "@type": "Organization",
    "name": "SoftCrafta",
    "url": "https://softcrafta.in/"
  },
  "areaServed": "Worldwide",
  "description": "SEO services for discoverability, technical quality, and search relevance."
}
```

## Example: FAQPage JSON-LD

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",

      "@type": "Question",

      "acceptedAnswer": {

        "text": "SoftCrafta provides website development, SEO, Google Business Profile optimization, and custom software development."
```

# 10. robots.txt

robots.txt controls crawler access and helps site owners guide search engine bots. It is useful, but it does not guarantee AI visibility or rankings.

## robots.txt responsibilities

- Allow important pages to be crawled
- Prevent accidental blocking of important URLs
- Point crawlers to the sitemap
- Keep public content accessible
- Review deployment changes carefully

## Good practice

- Ensure the site map is discoverable
- Do not block CSS, JS, or important page resources unless necessary
- Avoid blocking pages that should be indexed
- Review the file after deployment

## Important rule

robots.txt is not a guarantee of search or AI recommendation visibility.

# 12. llms.txt

llms.txt is a text file intended to help AI systems understand a site's purpose and content, but it is not a guaranteed AI visibility mechanism.

## What it is

A simple file that can summarize important content and service information for AI systems and crawlers.

## Difference from robots.txt

- robots.txt is about crawler access and site behavior
- llms.txt is about machine-readable content guidance and discovery context
- llms.txt is not a guarantee that a model will use it

## Example llms.txt

> This is an example only and should be verified before use.

```text
# SoftCrafta

> SoftCrafta is a web development and software services agency.

## Services

- Website Development
- SEO
- Google Business Profile Optimization
- Custom Software Development

## Website

https://softcrafta.in/
```

## Important caution

llms.txt is optional, experimental in practice, and should not be treated as a guaranteed path to AI citations or recommendations.
